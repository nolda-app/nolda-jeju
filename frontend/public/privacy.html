2. YouTube(Google) 데이터의 처리

  • 이용자가 직접 연결을 선택했을 때만 YouTube 읽기 전용 권한을 요청합니다. 동영상 업로드·수정·삭제, 댓글, 구독 변경 등 이용자의 YouTube 계정을 바꾸는 기능은 사용하지 않습니다.
  • 1회 분석 방식입니다. 분석이 끝나면 Google 접근 토큰은 즉시 폐기하고 저장하지 않으며, 이후 이용자의 YouTube 데이터에 다시 접근하지 않습니다.
  • 분석 결과(취향 요약과 대표 채널·영상 제목 일부)는 서버 메모리에만 임시로 보관하며 데이터베이스에 저장하지 않습니다. 서버가 재시작되면 삭제됩니다.
  • YouTube 데이터는 이용자에게 취향 분석 결과를 보여주고 코스를 추천하는 기능을 제공하는 목적으로만 사용합니다. 광고(개인 맞춤 광고 포함)에 사용하지 않으며, 판매하거나 데이터 중개업자·광고 플랫폼 등에 제공하지 않습니다.
  • Google 사용자 데이터를 일반적인(범용) AI·머신러닝 모델을 개발하거나 학습시키는 데 사용하지 않습니다.
  • 운영자의 직원이 이용자의 YouTube 데이터를 열람하는 일은 없습니다. 다만 ① 이용자가 특정 내용을 열람하도록 동의한 경우, ② 보안 사고 조사 등 보안상 필요한 경우, ③ 법령 준수에 필요한 경우는 예외입니다.
  • 이용자는 언제든 권한을 거둘 수 있습니다. Google 계정 > 보안 > 서드파티 앱 및 서비스 액세스에서 NOLDA를 선택해 접근을 삭제하세요.

운영자는 이용자의 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 서비스 제공에 필요한 범위에서만 아래 업체의 서비스를 이용합니다.

받는 자이전 국가항목목적·보유 기간
OpenAI, L.L.C. (AI 분석, OpenAI API) 미국 취향 분석 요청 시: 대표 채널명·구독 채널명·좋아요 동영상 제목 일부(각 최대 20개 안팎), 이용자가 고른 사진(축소본)과 촬영 시각·동네. 코스 생성 요청 시: 취향 요약과 요청 조건 취향 분석과 코스 생성 결과를 만들기 위해 이용 시점에 API로 전송합니다. 운영자는 이를 모델 학습 용도로 제공하지 않으며, OpenAI는 자체 정책에 따라 API 요청 기록을 일정 기간(오남용 방지 목적) 보관할 수 있습니다.
Supabase (데이터베이스 호스팅) 미국 회원 정보(ID, 이메일, 닉네임, 프로필 사진 주소), 생성·저장한 코스 회원 관리와 저장한 코스 제공 · 회원 탈퇴(삭제 요청) 시까지
Vercel 등 호스팅 사업자 미국 등 접속 기록(IP 주소, 기기·브라우저 정보) 서비스 제공과 오류 확인 · 사업자 정책에 따른 기간

이전은 서비스 이용 시 네트워크를 통해 이루어집니다. 국외 이전을 원하지 않으시면 YouTube·사진 취향 분석을 선택하지 않고 서비스를 이용하실 수 있으며, 이전된 정보의 삭제는 아래 문의처로 요청하실 수 있습니다.

4. 보유 및 이용 기간, 파기

  • 회원 정보와 저장한 코스: 회원 탈퇴 또는 삭제 요청 시까지 보관하고 지체 없이 파기합니다.
  • YouTube 분석 결과: 위 2항과 같이 서버 메모리에만 임시 보관되며 서버 재시작 시 삭제됩니다. Google 접근 토큰은 보관하지 않습니다.
  • 사진: 기기에서 축소한 뒤 분석 요청에 한 번만 쓰이며, 원본과 축소본 모두 서버에 저장하지 않습니다.
  • 관련 법령에서 보관을 요구하는 정보는 해당 기간 동안 분리해 보관한 뒤 파기합니다.
  • 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

6. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • 로그인 정보는 비밀번호를 저장하지 않고 Google·카카오 인증을 이용하며, 서비스 세션은 서명된 토큰으로 관리합니다.
  • API 키와 비밀 값은 서버 환경변수로만 관리하고, 데이터베이스 접근 권한을 최소한의 담당자로 제한합니다.

7. 쿠키 및 브라우저 저장소
